2 | source .venv/bin/activate (откл. deactivate)
3 | pip install rich pyfiglet

Before you start, you need to install two libraries:
pip install rich pyfiglet

If you're on Linux and it won't let you install, follow these steps:
1 | python3 -m venv .venv
2 | source .venv/bin/activate (to deactivate: deactivate)
3 | pip install rich pyfiglet
